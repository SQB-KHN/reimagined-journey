# Project instructions
Build an ethical, visually distinctive, mobile-first website for an emerging India-based rice trader. Use evidence-backed commercial claims only. Do not imply existing certifications, laboratory reports, export history, licenses, client names, supply guarantees or live enquiry processing without verification.

Work in phases: positioning brief -> Figma-approved design reference -> frontend implementation -> reviewed research/content -> testing/launch.
Follow project-local skills when relevant:
- tech-design-doc — evaluate architectural trade-offs
- tech-readiness-review — pre-launch checks
- marketing-positioning-brief — proof-backed market claims
- content-brief — reader, evidence and article structure
- frontend-design — design system and responsive quality checklist
- website-quality — a11y, technical SEO, functionality and copy validation

Never modify the archived GitHub Skills tutorial outside `website/` as part of this project.
