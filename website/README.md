# Field & Grain — rice trading website (working brand)

An editorial-style, responsive commercial website prototype under `website/`. The temporary name **Field & Grain** is a placeholder, not an established company identity.

## Run locally
```bash
cd website
npm install
npm run dev
```
Open http://localhost:3000 . Requires Node.js 20+.

## Scope
Five topical pages and a homepage, responsive CSS, accessible navigation and semantic HTML, example trade content with careful non-certification language. The contact form prepares/copies an enquiry and does **not** submit or persist data.

## Before publication
1. Approve company identity, logo and evidence-backed company claims.
2. Confirm all regulatory/commercial statements with applicable authorities and qualified advisers.
3. Build and test a secure real enquiry channel; add privacy notice, anti-spam and consent where required.
4. Add independently checked article citations and product specification sheets.
5. Run `npm install`, `npm run build`, responsive, keyboard, accessibility and browser tests.
6. Replace placeholder branding and obtain rights for any photography or third-party assets.
