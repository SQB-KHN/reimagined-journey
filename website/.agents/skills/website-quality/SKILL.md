# Website Quality Gate
- Content: verify claims and sources, product details, contact information, no implied certifications or fabricated performance.
- SEO: unique metadata, heading hierarchy, canonical URLs after domain selection, sitemap and robots files after publication strategy.
- Accessibility: keyboard paths, landmark regions, labels, focus states and contrast.
- Performance: audit bundle and media; optimize imagery after rights are verified.
- Security: never commit API keys; secure real forms with validation, rate limits, spam prevention and privacy notice.
- Operational: run build, link checking, responsive tests and rollback planning.
- Mark every check PASS, FAIL, or NOT YET TESTED; never infer a passed check from the presence of source code.
