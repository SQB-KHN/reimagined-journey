# Frontend Design
1. Start with the approved visual baseline and define typography, spacing, colors, grids and responsive breakpoints.
2. Create reusable semantic components and maintain a consistent editorial hierarchy.
3. Verify contrast, keyboard access, focus indicators, headings, labels and touch targets.
4. Check 375px, 768px, 1280px and 1600px widths and reduce layout shift.
5. Do not claim visual parity with Figma unless a comparison has been performed.
6. Confirm mobile navigation, links and calls to action in browser tests.
